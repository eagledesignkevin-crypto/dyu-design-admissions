# 大葉大學設計學系｜116學年度招生網站 V1 互動式原型

## 預覽
直接雙擊 `index.html`，即可在 Chrome、Edge 或 Safari 開啟，不需安裝 Node.js 或額外套件。

## 已完成
- 瑞士極簡 × Apple 風格響應式首頁
- 工業設計／視覺傳達兩組介紹
- AI × 設計 × 實作歷程
- 六件 SVG 示範作品、分類篩選與組別快速切換
- 四年學習旅程互動切換
- 116 招生資訊入口、外部官方網站連結
- 手機版選單、卷動進場效果、降低動態偏好支援

## 重要聲明
本網站是**非官方示範原型**。作品是 SVG 插畫示意，非實際學生作品。招生名額、時程、獎助學金、LINE 聯絡與預約功能尚未接入，請依大葉大學正式公告為準。正式上線前請確認文字、校徽／識別規範及作品使用授權。

## 正式化待辦
1. 更換學生作品為獲授權照片與設計圖。
2. 依核定課程地圖修訂四年學習說明。
3. 補上招生簡章、正式招生頁及諮詢渠道。
4. 依學校識別規範替換暫用 D. 標誌。
5. 部署至學校核准域名，依校方政策補上隱私聲明。

## GitHub Pages 部署與更新

取得公開核准後，將本專案推送到 GitHub。於儲存庫 Settings → Pages 選擇 Deploy from a branch，指定 `main` 與 `/(root)`。網站根目錄為 `index.html` 所在資料夾，無需建置。

更新時先在本機預覽，再提交並推送至 `main`。等待 Pages 部署完成，使用後台顯示的 HTTPS 網址確認更新。

網站從 Google Fonts 載入字型。連線失敗時會使用備用字型。
